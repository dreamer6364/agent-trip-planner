# 后端模块架构文档

## 模块总览

本项目采用微服务架构，共包含 **7 个后端模块**：

```
trip-planner-parent/
├── common-module/          # 公共模块
├── auth-service/           # 认证服务
├── gateway/                # API 网关
├── trip-service/           # 行程服务
├── plan-service/           # 规划服务
├── planning-worker/        # 规划工作器
└── notification-service/   # 通知服务
```

---

## 1. common-module（公共模块）

**职责**: 提供跨服务共享的工具类、DTO、安全组件

│   └── GlobalExceptionHandler.java  # 全局异常处理
├── security/               # 安全组件
│   ├── GatewayHeaderAuthFilter.java  # 网关认证过滤器
│   └── JwtAuthenticationToken.java   # JWT 认证令牌

│   ├── GeoUtils.java       # 地理位置工具

## 3. gateway（API 网关）

**职责**: 路由转发、JWT 鉴权、限流、熔断、静态资源服务

### 包结构

```
com.tripplanner.gateway
├── config/                 # 配置
│   ├── RouteConfig.java            # 路由配置
│   ├── SecurityConfig.java         # 安全配置
│   ├── RateLimiterConfig.java      # 限流配置
│   ├── CircuitBreakerConfig.java   # 熔断配置
│   ├── GatewayFilterConfig.java    # 过滤器配置
│   └── StaticResourceConfig.java   # 静态资源配置
├── filter/                 # 过滤器
│   ├── JwtAuthenticationFilter.java  # JWT 认证过滤器
│   └── RequestLoggingFilter.java     # 请求日志过滤器
└── handler/
    └── FallbackHandler.java    # 熔断降级处理
```

### 路由规则

| 服务 | 路径前缀 | 目标地址 |
|------|----------|----------|
| Auth Service | `/api/auth/**` | `lb://auth-service:8081` |
| Trip Service | `/api/trips/**` | `lb://trip-service:8082` |
| Plan Service | `/api/plans/**` | `lb://plan-service:8083` |
| Notification | `/ws/**` | `lb://notification-service:8085` |

### 核心功能

- **JWT 认证**: 从 Header 提取 Token 并验证
- **限流**: 基于 Redis 的令牌桶限流（默认 100 req/s）
- **熔断**: 基于 Resilience4j 的熔断降级
- **静态资源**: 服务前端 HTML/JS/CSS

### 端口: 8080

## 6. planning-worker（规划工作器）

**职责**: 消费 Kafka 任务、执行约束求解、路线优化

### 包结构

```
com.tripplanner.worker
├── consumer/               # Kafka 消费者
│   ├── PlanningJobConsumer.java    # 规划任务消费者
│   └── ReplanJobConsumer.java      # 重规划消费者
├── service/                # 业务逻辑
│   ├── PlanningOrchestrator.java   # 规划编排
│   ├── GeocodeClient.java          # 地理编码客户端
│   ├── InputParsingClient.java     # 输入解析客户端
│   ├── ProgressPublisher.java      # 进度发布
│   └── ResultPersistService.java   # 结果持久化
├── solver/                 # 求解器
│   ├── CpSatSolver.java            # OR-Tools CP-SAT 求解
│   ├── HeuristicSolver.java        # 启发式求解
│   ├── IncrementalReplanner.java   # 增量重规划
│   └── model/
│       ├── PlanningProblem.java    # 规划问题模型
│       ├── TravelMatrix.java       # 距离矩阵
│       └── ActivityVar.java        # 活动变量
├── dto/
│   └── SolverResult.java
└── config/                 # 配置
    ├── KafkaConsumerConfig.java
    ├── OrToolsConfig.java
    └── SolverConfig.java
```

### Kafka Topic

| Topic | 说明 |
|-------|------|
| `planning-jobs` | 规划任务队列 |
| `replan-jobs` | 重规划任务队列 |
| `planning-events` | 规划事件（进度、完成、失败） |

### 核心功能

- **约束求解**: OR-Tools CP-SAT 精确求解
- **启发式算法**: 贪心 + 2-opt + 模拟退火（大规模问题）
- **增量重规划**: 基于用户反馈的局部调整
- **进度发布**: 通过 Redis PubSub 发布进度

### 端口: 无 HTTP 端口（纯 Kafka 消费者）

## 模块依赖关系

```
┌─────────────────────────────────────────────────────────────┐
│                          Gateway                            │
│                    (路由、鉴权、限流)                          │
└─────────────────────────────────────────────────────────────┘
                              │
         ┌────────────────────┼────────────────────┐
         ▼                    ▼                    ▼
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│ Auth Service│      │ Trip Service│      │ Plan Service│
│   (认证)     │      │   (行程)     │      │   (规划)     │
└─────────────┘      └──────┬──────┘      └──────┬──────┘
                            │                     │
                            │    ┌────────────────┘
                            │    │   Kafka
                            ▼    ▼
                     ┌─────────────────┐
                     │Planning Worker  │
                     │   (求解优化)      │
                     └────────┬────────┘
                              │   Redis PubSub
                              ▼
                     ┌─────────────────┐
                     │  Notification   │
                     │  (WebSocket)    │
                     └─────────────────┘
```
